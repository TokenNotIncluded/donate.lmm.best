# TOKEN visual direction

The user pinned ASCII art plus an interactive token cloud and approved the proposed independent-creator / terminal cultural direction. That pinned direction takes priority over the concept seed assignment (e148a1dd). No alternative identity or image mockup is needed to implement character art.

## World
A late-night ASCII demo: charcoal ink, warm off-white lettering, acid-lime actions, an enormous procedural ASCII orbital sculpture with a cloud of clickable text tokens. Flat editorial composition and sharp thin rules, no SaaS cards or fabricated metrics. Actual character art serves as the primary visual asset. Dense operational admin shares the palette while using ordinary labeled forms and tables.

## Type and material
Self-hosted open licensed geometric display face if available; readable system Chinese sans for paragraphs; monospace only for ASCII, token labels, amounts and machine data. Lime reserved for interaction and selection. No neon blur, no fake terminal logs.

## Signature interaction
Pointer subtly rotates the living ASCII sculpture; tapping cloud tokens emits a visible brief pulse. Donation amount choices influence the scene. Pointer controls have keyboard equivalents, motion respects reduced-motion and sleeps when hidden. Donation remains usable when art fails.
